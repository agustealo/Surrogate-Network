# Reviewed documentation screenshots

This directory stores reviewed, web-optimized documentation derivatives of the exact-head runtime screenshots generated by the consumer E2E rail. Source PNG evidence remains available in the corresponding GitHub Actions `consumer-visual-evidence` artifact.

The four numbered lifecycle WebPs are focused single-surface documentation evidence. `05-showcase-grid.webp` is a compact derivative of six additional reviewed runtime frames covering Discovery, member safety, account controls, Admin Console, moderation reports, and Community Principles.

Do not hand-author or fabricate replacement screenshots. Regenerate source evidence through `e2e/smoke.spec.ts`, inspect the exact-head artifact, and only then promote documentation derivatives.
